# Проверка GitHub Pages демосборки

Проверены локально:

- Синтаксис JavaScript (`node --check`), без ошибок.
- Выбор десяти различных вымышленных анкет, затем экран окончания и сброс.
- Лайк переводит страницу в состояние одного чата, меняет подпись в меню и блокирует просмотр других анкет.
- Тестовое сообщение сохраняется в текущем браузере.
- Отмена завершения чата не снимает ограничений. Подтверждённое завершение открывает следующую анкету.
- Локальное сохранение собственного профиля после повторной инициализации страницы.
- Редактор цветов и живой предпросмотр.
- Модальные окна демонстрационных встреч.
- Вёрстка без горизонтального переполнения на ширинах 1440, 390 и 320 пикселей.
- Проверены ответы HTTP 200 на главный HTML и JavaScript.

Проверки интерактивности в Chromium выполнялись через локальную инъекцию HTML/CSS/JS, поскольку в этой среде браузер запрещает сетевую навигацию к localhost. Реальную публикацию на GitHub Pages и открытие сайта в интернете должен выполнить владелец репозитория.

Это **проверка демо**, не тест регистрации, настоящей доставки сообщений, защиты аккаунтов или production-базы данных: таких компонентов в GitHub Pages сборке нет.
