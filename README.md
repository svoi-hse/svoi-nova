# Свои — OneLove / GitHub Pages

Это публичная интерактивная демонстрация визуального стиля NOVA и механики OneLove. Сборка специально подготовлена для GitHub Pages: никаких установок, терминала, базы данных или сервера для её публикации не требуется.

**Это НЕ полноценный сайт знакомств.** GitHub Pages публикует только статические страницы. Здесь нет регистрации по почте, входа по паролю, реального подбора между людьми, доставки сообщений, прав администраторов и записи на встречи.

## Что можно проверить

- Десять **вымышленных** анкет. Показывается строго одна, отказ открывает следующую.
- Лайк превращает кнопку OneLove в чат и блокирует остальные анкеты до подтверждённого завершения.
- Локальные демонстрационные сообщения (никому не отправляются).
- Живой редактор своей карточки с фонами, цветами, типографикой, композициями и локальным фото.
- Сохранение настроек в `localStorage` **только этого браузера**. Очистка данных сайта удалит демоданные.
- Мобильный интерфейс и переходы. Работает без внешних JS-библиотек.

## Если нужен настоящий сайт знакомств

В архиве `Svoi_NOVA_v2_0_GitHub_Release.zip` находится серверная версия. Чтобы люди могли регистрироваться и общаться между устройствами, ей нужен сервер, постоянная база данных, защищённые API и модерация. GitHub Pages не запускает Python/SQLite и не может безопасно хранить пользовательские пароли и личную переписку.

**Не используйте эту демосборку для сбора персональных данных студентов.** Она не связана официально с НИУ ВШЭ.
